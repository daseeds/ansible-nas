# 05: Enable controller-based Steam Remote Play

**What to build:** The couch user can use Xbox-compatible and Nintendo Switch controllers with `athena` as a Steam Remote Play client, streaming a game from the separate Linux gaming PC.

**Blocked by:** 03: Add the opt-in Steam couch session.

**Status:** ready-for-agent

- [ ] Steam recognizes and supports the Xbox-compatible controller in the TV session.
- [ ] Steam recognizes and supports the Nintendo Switch controller in the TV session.
- [ ] The user can manually pair/sign in and start a Remote Play stream from the separate Linux gaming PC.
- [ ] Controller input works during a streamed game and the session can return to Big Picture afterward.
- [ ] Keyboard/mouse remains available for setup and troubleshooting.
- [ ] No Steam credentials are stored in inventory or automation.
