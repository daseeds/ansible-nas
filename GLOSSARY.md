# Glossary

This single-context glossary defines terms used in repository discussions and documentation.

| Term | Definition |
| --- | --- |
| **NAS host** | The computer managed by Ansible-NAS to provide network-attached storage and its configured services. |
| **TV endpoint** | The NAS host's optional role as a device used at a television for local couch-oriented interaction. This does not replace its NAS-host responsibilities. |
| **Steam Remote Play client** | The Steam installation on the TV endpoint that receives a game stream from a separate gaming computer; the game runs on that other computer. |
